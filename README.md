# Gangcheng (Felix) Xu 徐岗程 — Academic Website

This is a static website designed for free hosting on GitHub Pages.

## Publish for free

1. Create a free GitHub account.
2. Create a public repository named exactly `YOUR-USERNAME.github.io`.
3. Extract this ZIP file.
4. Upload every file and the `assets` folder to the repository root.
5. Open **Settings → Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Select `main` and `/ (root)`, then save.
8. Your site will appear at `https://YOUR-USERNAME.github.io`.

## Edit later

- Main page: `index.html`
- Design: `styles.css`
- Mobile menu and animations: `script.js`
- Images and logo: `assets/`
- Map markers: search for `const sites` in `index.html` and `fieldsites.html`

## Important placeholders

Replace the Google Scholar, ORCID, and ResearchGate placeholder links in `contact.html` with exact profile URLs.
Add a PDF CV later if desired.


## Research privacy

The website intentionally presents the doctoral project only at a high level. Detailed research questions, fieldwork design, participant groups, and analytical plans should not be added to the public site unless you decide to make them public.
