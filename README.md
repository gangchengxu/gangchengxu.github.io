# Gangcheng (Felix) Xu — Academic Website

This is a static academic website prepared for free hosting on GitHub Pages.

## Main files

- `index.html` — Home
- `research.html` — Research
- `publications.html` — Selected publications
- `conferences.html` — Academic conferences
- `cv.html` — Curriculum vitae
- `contact.html` — Contact and academic profiles
- `styles.css` — Site design
- `script.js` — Navigation and reveal effects
- `assets/` — Logo and background image

## Publish free with GitHub Pages

1. Create a public GitHub repository named `YOUR-USERNAME.github.io`.
2. Upload all files and the `assets` folder to the repository root.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**.
6. Save and wait a few minutes.

Your site will appear at `https://YOUR-USERNAME.github.io`.

## Important when replacing an older version

Delete the old `fieldsites.html` and `presentations.html` files from the GitHub repository. They are no longer part of the site.
